# 广告快跳（AdAuto）

一个 Android 悬浮球小工具：**屏幕角上常驻一个小球，自动帮你跳过短剧 App 里的广告**。
不用 Root、不用装 Xposed、也不用改别人的 App。

> 🎯 目前**只针对「红果免费短剧」（`com.phoenix.read`）做了完整适配**，其它 App 不保证。
>
> 💬 反馈、提建议、发广告截图：Telegram 群 [AdAuto 用户交流群](https://t.me/+I5jUPxmH_jA0OWNh)

---

## 一、它是什么（用了哪些系统能力）

| 用到的能力 | 干什么 |
| --- | --- |
| 无障碍服务（AccessibilityService） | 读取当前屏幕上的控件文字与结构，判断"这是不是广告" |
| 手势（dispatchGesture） | 隔空"上滑"把广告划走 |
| 点击（无障碍点击） | 点掉"跳过 / 关闭 / 知道了"这类按钮 |
| 悬浮窗（显示在其他应用上层） | 显示那个可以拖动的小球 |
| 前台服务 | 让你切到短剧 App 之后它还能一直在岗 |

它**不是在破解 App**：规则就是"看到'上滑继续观看'这几个字，就帮你上滑一下"，
看到"跳过 5s"就帮你点掉。判断全部在本机完成，规则写死在安装包里，没有云端服务。

小球的操作：

| 操作 | 作用 |
| --- | --- |
| 拖动 | 放到顺手的位置 |
| 单击 | 开关"自动跳过"（球变灰 = 已关闭） |
| 长按 | 打开设置页 |

## 二、隐私：它**没有联网权限**

最硬的一条：

> **本应用没有申请 `INTERNET` 权限，物理上没法把任何东西发到任何服务器。**

它只申请了 4 项权限，全部是干正事用的：

| 权限 | 用途 |
| --- | --- |
| 无障碍服务 | 读界面、执行点击与上滑 |
| 悬浮窗（显示在其他应用上层） | 显示悬浮球、调试浮层 |
| 前台服务（specialUse） | 后台常驻，切走后不被系统挂起 |
| 通知（Android 13+） | 前台服务要求的那条常驻通知 |

可以自己核验（连电脑执行，Windows 用 `findstr`，mac/linux 换成 `grep`）：

```bash
adb shell dumpsys package com.wisight.adauto | findstr "android.permission"
```

列表里**不会**出现 `android.permission.INTERNET`。

其它几点：

- **横屏时会截图？** 只在**内存里**统计颜色与形状（判断画面上有没有一个橙色按钮），
  **不保存、不上传**，算完即丢。只截当前屏幕，不截别的。
- **没有第三方统计 / 广告 SDK**，不申请设备标识（IMEI / OAID / ANDROID_ID）类权限。
- **不做实名、不用注册、不用联网激活**。
- **不会自动上报任何信息**。要反馈时，是**你自己**把调试信息复制出来发到群里（见第五节）。

## 三、适用范围

- ✅ **红果免费短剧（`com.phoenix.read`）**：完整适配，覆盖多种广告形态
  （原生图文广告、试玩广告、直播样式广告、横屏全屏广告等）。
- ⚠️ **其它 App**：只能靠通用关键字兜底（"上滑继续观看 / 跳过广告 / 关闭 / 倒计时"）。
  能用不代表可靠 —— 文字画在视频里读不到、界面结构不同，都可能漏判或误判。
- 🚫 **不是"去 VIP"**：只跳广告，不碰会员内容和付费。

默认开启「**仅检测下方列表里的 App**」（列表默认只有红果），避免在聊天、桌面、
系统设置里把"广告 / 关闭 / 跳过"这类字样当成广告去点。

> 想让它在别的 App 里也试？可以在「规则设置」里追加包名，但要自控风险：
> 误判时会帮你乱点。建议保持「仅检测下方列表」打开。

## 四、安装与使用

### 安装步骤

1. 拿到 **release 签名包**（`app-release.apk`）。
   ⚠️ 别用 `app-debug.apk` —— 小米 / HyperOS 会拒绝给 debug 包敏感权限。
2. 允许手机"安装未知来源应用"，装好后打开 App。
3. 页面里依次点三个按钮授权：
   - **无障碍服务**（必开）
   - **悬浮窗权限**（必开）
   - **通知权限**（Android 13+）
4. 确认「自动跳过广告」「显示悬浮球」两个开关是**开**的。
5. 回到桌面，左上角出现小球，开始工作。

### 可能遇到的问题

**① 提示"未知来源应用，系统已拒绝此应用获取敏感权限"，无障碍打不开**
装的是 debug 包。换 release 包；若手机里已装过不同签名的旧包，先卸载再装（设置会丢，需重新授权）。

**② 无障碍明明开着，过一阵自己失效了（小米 / HyperOS 常见）**
系统会静默清掉无障碍设置（强行停止过、清理后台、重启、长期未用）。
- 去 设置 → 无障碍 → 广告快跳，重新打开；
- 或者连电脑一条命令恢复：
```bash
adb shell settings put secure enabled_accessibility_services com.wisight.adauto/.service.AdSkipAccessibilityService
adb shell settings put secure accessibility_enabled 1
```
- 减少复发：最近任务里把 App **加锁**，打开**自启动**，省电策略设为**无限制**。

**③ 覆盖安装（升级）后，小球不见了**
重新打开一次 App 主界面即可（系统授权页弹出来是正常的）。
仍然没有：设置 → 应用 → 广告快跳 → 显示在其他应用上层，确认是"允许"。

**④ 装不上 / 提示签名不一致**
新旧包签名不同（混装过 debug 包或换过签名）。只能卸载重装，设置会丢。

**⑤ 我把「显示悬浮球」关了，球看不见了，但广告还在自动跳**
这是设计如此：关掉球只是让它**完全透明**（窗口和后台服务都保留），
否则小米会在 20 秒左右把进程挂起，自动跳过就失效了。
想**彻底退出**，把「自动跳过」和「显示悬浮球」**都关掉**。

## 五、广告跳不过怎么办

我们**不做**自动上报。反馈走"你自己复制、自己发群"这条路：

1. 打开 App → 设置页 → **调试 → 显示判定详情浮层**（即时生效）。
2. 回到那条**跳不过的广告**，让它停在屏幕上（别划走、别退出）。
3. 点浮层上的 **「复制」**（点浮层任意位置也行），会提示"调试信息已复制"。
4. 到**群里粘贴发出来**，顺手补一句"什么 App、哪种广告"。有截图更好。

复制出来的内容大概长这样（前几行是判定详情，后面是环境信息）：

```
#74
fg=com.phoenix.read  1200x2670
nodes=85/117 textLen=92
rv=false tex=false adItem=false
sparse=false cd=false landNoSurf=false
surface=true scroll=true webView=false
cls=FrameLayout×38,ViewGroup×21,ImageView×9,TextView×6
→ 未命中任何广告规则
———— 环境信息（仅你主动复制时生成，App 不会后台上传）————
app=1.2.4(10204)
device=Xiaomi 23127PN0CC
android=16 SDK=36
rom=OS3.0.307.0.WNCCNXM (BP2A.250605.031.A3)
screen=1200x2670 dpi=480 竖屏
target=com.phoenix.read ver=7.3.9.32
time=2026-11-04 11:19:47
```

后半段**只有**：本应用版本、手机型号、系统版本、分辨率 / dpi / 横竖屏、
目标 App 的版本、复制时间。**没有**页面文字、**没有**截图、
**没有**其它 App 列表、**没有**设备标识。你不点复制，它什么都产生不了。

### 关于调试浮层

- 浮层显示最近一次判定：前台包名、屏幕尺寸、节点数、各特征值、最终结论；
  被拦在闸门时显示 `闸门未通过：<原因>`。
- 它**不影响判定**：不抢焦点、对无障碍服务完全隐身（自己也是无障碍服务，同样读不到它）。
  唯一代价是右上角那一小块区域不再把手势传给下面的 App。
- **调试浮层开着时一定会检测**（哪怕"自动跳过"是关的），但不会动手 ——
  浮层会标注 `【仅调试·不执行】`，方便"只看不改"地观察。
- 不需要了就把开关关掉，浮层和它的检测负担一起消失。

**各字段含义**（发反馈时不用解释，我们看得懂）：

| 字段 | 含义 |
|---|---|
| `nodes=A/B` | A = 过滤后有特征的节点数，B = **过滤前的可见节点总数** |
| `textLen` | 无障碍树里能读到的文字总量（**0 = 创意是自绘的，读不到任何字**） |
| `rv` / `tex` / `adItem` | 直播渲染视图 / 无 id 的 TextureView / 广告 item 容器（`ay0`+`i0t`） |
| `sparse` | 竖屏“稀疏树”兜底判据 |
| `cd` | 是否读到广告倒计时 |
| `surface` | 页面是否有视频层（SurfaceView/TextureView/VideoView） |
| `scroll` | 页面是否有可滚动容器（列表/网格/ViewPager） |
| `webView` | 页面是否有 WebView（试玩/落地页广告常用） |
| `landNoSurf` | 横屏「读不到字 + 连视频层都没有」判据 |
| `cls` | 类名直方图（**只在开浮层时统计**）——用来判断创意到底怎么渲染的 |

**两条不读文字的兜底判据**（都在截图后台线程做像素统计，不做 OCR）：

1. **横屏无视频层**：横屏 + `textLen≈0` + `surface=false`。
   正剧播放必然有视频层（缓冲/加载/暂停时它都在），没有视频层说明画面不是播放器渲染的。
2. **底部「∧ 上滑继续看短剧」提示栏**：画面底部有纯黑底 + 居中白字的提示栏。
   这条栏是 App 自己的 UI，等于"你现在不在正剧播放页"，但文字读不到，只能视觉识别。
   实测阈值：栏高 4%~20%、黑底 ≥0.90、白字占比 0.0006~0.10、
   白字横向跨度 0.05~0.55 且水平居中（系统三键导航栏图标跨度约 0.8，会被排除）。
   **横屏正剧没有这条栏**，因此不会误判。
   判定需**两张不同截图都命中**，与橙色按钮判据一致。

## 六、构建（开发者）

环境：JDK 17+、Android SDK（compileSdk 34）。

```bash
./gradlew assembleRelease     # 发布包，自动用 keystore/adauto.keystore 签名
```

产物：`app/build/outputs/apk/release/app-release.apk`

安装：`adb install -r app/build/outputs/apk/release/app-release.apk`

> ⚠️ `keystore/adauto.keystore` 与 `keystore.properties` **不在仓库里**，请离线备份。
> 丢了就无法给老用户无缝升级，只能卸载重装（旧设置全部丢失）。

### 界面诊断脚本

`tools/ui-diagnose/` 下有一组排查「为什么这条广告没跳过」的脚本
（抓界面、按规则判定、复刻匹配逻辑、对比广告页与正剧页等），
只做取证与分析，不操作手机。用法见 [tools/ui-diagnose/README.md](tools/ui-diagnose/README.md)。
